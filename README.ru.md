# xonevertr

[English](README.md) · **Русский**

Нативное приложение macOS для конвертации FLAC → WAV без потерь. Перетащите
файлы или папки, запустите очередь и откройте результат в Finder.

SwiftUI и потоковый FLAC-декодер на Swift. Для работы приложения не нужны
Python, Homebrew, ffmpeg или подключение к сети.

## Возможности

- Пакетная конвертация, вложенные папки и перетаскивание файлов.
- Сохранение исходной частоты и разрядности 16/24 бит, моно или стерео.
- Обычный PCM WAV, включая 24-битный звук; теги ID3 и обложки.
- Проверка кадров CRC8/CRC16 и сверка MD5 из STREAMINFO, если он указан.
- Прогресс, отмена, повтор ошибок и открытие результата в Finder.
- Атомарное сохранение без перезаписи существующих файлов и изменения исходников.
- Системная светлая/тёмная тема и горячие клавиши.

## Установка

Требуется **macOS 14 или новее**. Текущий локальный установщик — для Apple Silicon.

Соберите установщик по инструкции ниже или скачайте артефакт успешного
[запуска macOS workflow](https://github.com/mrzenxxx/xonevertr/actions/workflows/macos.yml),
когда он станет доступен. Откройте `.pkg` и завершите установку в стандартном
окне macOS. Приложение установится в `/Applications/xonevertr.app`;
запускайте его из «Программ» или через Spotlight.

Приложение имеет локальную ad-hoc подпись. Установщик не подписан;
подписи Developer ID и нотариализации Apple у этих сборок нет.

## Использование

1. Перетащите FLAC или папки в окно либо выберите их через **⌘O**.
2. Нажмите **Return** или «Конвертировать». Для остановки — **Escape**.
3. Нажмите кнопку папки у готового трека, чтобы показать WAV в Finder.

Интерфейс приложения сейчас на русском языке.

По умолчанию папка `Album` превращается в соседнюю `Album WAV` с сохранением
подпапок. При выборе общей папки все результаты складываются в неё.
Место вывода применяется к следующим добавляемым файлам; назначение каждого
файла видно под его именем в очереди.

Совпадающие имена получают суффиксы `(2)`, `(3)`. Если файл назначения появился
во время конвертации, приложение сообщит об ошибке вместо его перезаписи.

## Сборка

Требуются **Swift 6+** и Command Line Tools или Xcode на macOS:

```sh
git clone https://github.com/mrzenxxx/xonevertr.git
cd xonevertr
scripts/test.sh
scripts/build-installer.sh
open dist/xonevertr.app
```

Результаты в `dist/`:

- `xonevertr.app` — приложение.
- `xonevertr-<version>-macos-<architecture>.pkg` — нативный установщик.
- `xonevertr-macos-<architecture>.zip` — архив приложения.

Сборка выполняется для архитектуры текущего Mac. Только приложение:
`scripts/build-app.sh`. Упаковка готовой сборки:
`scripts/build-installer.sh --skip-build`.

## Ограничения и проверки

Поддерживаются FLAC 16/24 бит, моно и стерео. Другая разрядность,
многоканальный звук и результат свыше предела обычного RIFF WAV около 4 GiB
отклоняются. Совместимость с конкретной моделью CDJ зависит также от её
поддерживаемых частот и разрядности; на физическом CDJ приложение не проверялось.

Тесты проверяют точные PCM-семплы для разных предикторов и режимов стерео FLAC,
заголовки WAV, Unicode-теги, обложки, контрольные суммы, повреждения, отмену,
гонки при сохранении, обход папок и совпадения имён. Аудиофайлы для тестов
синтетические. ffmpeg нужен только для их пересоздания, а не для сборки,
тестирования или работы приложения.
